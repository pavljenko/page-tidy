# Page Tidy

**Прячет рекламу и любые ненужные элементы интерфейса по клику — там, где обычный блокировщик не справляется.**

[Установить из Chrome Web Store](https://chromewebstore.google.com/detail/jooponlkealniaohbbfkdebklphmdpfp)

</div>

---

Наводите курсор — рамка показывает, что будет скрыто. Клик — элемент исчезает навсегда: он останется скрытым после перезагрузки страницы, перезапуска браузера и повторного входа на сайт.

![Режим выбора элемента](docs/picker.png)

## Установка

Ставьте расширение [из Chrome Web Store](https://chromewebstore.google.com/detail/jooponlkealniaohbbfkdebklphmdpfp). Оно работает в Chrome, Яндекс Браузере, Edge, Opera, Brave и Vivaldi — все они устанавливают расширения из этого каталога.

> [!IMPORTANT]
> В Яндекс Браузере ставьте только из каталога. Расширение, установленное из папки в режиме разработчика, браузер через некоторое время отключает сам: он так поступает со всеми расширениями из непроверенных источников.

## Как пользоваться

Нажмите <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd> прямо на странице или откройте меню расширения и выберите «Скрыть элемент на странице».

| Действие | Что делает |
| --- | --- |
| наведение | подсвечивает элемент и показывает, что именно будет скрыто |
| клик | прячет элемент навсегда |
| <kbd>↑</kbd> / <kbd>↓</kbd> | расширить выделение на родителя, сузить на потомка |
| <kbd>⌘</kbd>+<kbd>Z</kbd> | вернуть только что скрытое |
| <kbd>Esc</kbd> | выйти из режима выбора |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | временно показать скрытое, не теряя правил |

Стрелка <kbd>↑</kbd> — самое полезное. Если кликнуть по надписи внутри баннера, скроется только надпись. Нажмите <kbd>↑</kbd> пару раз, чтобы захватить баннер целиком: рамка покажет, что попадёт под нож.

![Меню расширения со списком правил](docs/popup.png)

В меню расширения видно все правила для текущего сайта. Любое можно временно выключить галочкой или удалить крестиком. Кнопки «Экспорт» и «Импорт» переносят настройки на другой компьютер.

## Почему обычный блокировщик здесь бессилен

Разметка рекламного блока во многих интерфейсах выглядит так:

```
[data-testid="page-layout_right-column_container_v1"]   ← стабильный якорь
  └ div.qotZC25wki5T0siGB          ← случайный класс
      └ div#qisQB2Jg_lvvqqSA       ← случайный id
          └ div.fd4459410          ← случайный класс, здесь сама реклама
```

Внутренние классы и id генерируются заново при каждой сборке, поэтому статические косметические правила за них зацепиться не могут. Но снаружи остаются `data-testid` и `qa-*` — хуки для автотестов, их не обфусцируют, иначе сломаются собственные тесты разработчиков сайта.

Page Tidy строит селекторы именно по таким атрибутам, а сгенерированные токены отбрасывает как ненадёжные:

```
PageLayout-m__body--xjMc4  → PageLayout-m__body    (стабильная часть)
qa-LeftColumn-Footer-Promo → qa-LeftColumn-Footer-Promo
UserWidget-Content_loading → UserWidget-Content     (хвост-состояние срезан)
qotZC25wki5T0siGB          → отброшен
fd4459410                  → отброшен
```

Если разметка всё-таки поедет, у каждого правила есть запасные селекторы и сигнатура элемента — тег, атрибуты и положение относительно якоря. По ней элемент находится заново.

## Готовые правила

Для Яндекс Почты правила уже написаны: рекламная колонка справа, промо-карусель в левой колонке, баннер Нейрофильтра включены сразу. Кнопка «+1 ТБ», промо-ссылка в подвале, блок подписок и другие включаются галочкой в меню расширения.

Правила для новых сайтов дописываются в [`presets.js`](presets.js).

## Приватность

Все настройки лежат в `chrome.storage.local` на вашем компьютере. Расширение не делает сетевых запросов, ничего не собирает и никуда не передаёт.

Селекторы намеренно не сохраняют содержимое страницы: `aria-label` длиннее 60 символов игнорируется, тексты с адресами и ссылками — тоже. Это важно, потому что в почтовых интерфейсах `aria-label` строки письма может содержать весь его текст.

## Сборка из исходников

```bash
git clone https://github.com/pavljenko/page-tidy.git
```

Затем откройте `chrome://extensions/`, включите режим разработчика и нажмите «Загрузить распакованное расширение», выбрав папку репозитория. В Яндекс Браузере такая установка со временем отключается — смотрите предупреждение выше.

Иконки и картинки для каталога генерируются из геометрии, вручную их не правят:

```bash
python3 make-icons.py
```

Скрипту нужен [Pillow](https://pypi.org/project/Pillow/). Он перезаписывает `icons/*.png`, `store-icon-128.png` и `promo-tile-440x280.png`.

Архив для загрузки в каталог:

```bash
zip -r page-tidy.zip manifest.json background.js content.js presets.js popup.html popup.js icons -x '.*'
```

## Структура

| Файл | Назначение |
| --- | --- |
| `manifest.json` | манифест расширения, Manifest V3 |
| `content.js` | движок селекторов, применение правил, режим выбора |
| `background.js` | ранняя вставка CSS, чтобы блоки не мигали при загрузке |
| `presets.js` | готовые правила для известных сайтов |
| `popup.html`, `popup.js` | меню управления правилами |
| `make-icons.py` | генератор иконок и картинок для каталога |
