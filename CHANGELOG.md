# История изменений

## 1.0.1

- Иконки перерисованы из геометрии: сглаженные края и ровные промежутки на всех размерах.
- Убрано лишнее разрешение `tabs` — доступ к вкладкам уже покрыт разрешением на доступ к сайтам.

## 1.0.0

Первая версия в Chrome Web Store.

- Скрытие элемента по клику, выделение родителя и потомка стрелками, отмена последнего действия.
- Селекторы по стабильным атрибутам с запасными вариантами и сигнатурой элемента.
- Готовые правила для Яндекс Почты.
- Временный показ скрытого, экспорт и импорт настроек.
